# Арена Парковка — Android-обёртка

Минимальное нативное приложение (Kotlin + WebView), которое открывает официальную страницу
оплаты парковки стадиона: **https://scbarena-nn.ru/parking/**.

Приложение — это только окно. Никакой собственной логики оплаты, никаких подмен данных.

## Что делает

| Возможность | Как реализовано |
|---|---|
| Полноэкранная страница | `Theme.Material3.DayNight.NoActionBar`, WebView на всю область |
| Переходы по сайту | остаются внутри WebView (включая шаги оплаты на стороне сайта) |
| Кнопка «Назад» | листает историю WebView, на корневой странице — выход |
| Обновление | pull-to-refresh + прогресс-бар загрузки |
| Cookies и сессии | `CookieManager`, включая сторонние cookies (нужны платёжным шлюзам) |
| Ошибка сети | экран «Страница не загрузилась» с кнопкой «Повторить» |
| `tel:`, `mailto:`, `geo:`, `intent:` | передаются системе (звонок, почта, карты) |
| Соцсети (vk, t.me, youtube) | открываются в отдельных приложениях/браузере |
| `window.open` / `target="_blank"` | открывается в том же WebView |
| Запрос камеры/микрофона сайтом | автоматически отклоняется |
| Восстановление после сворачивания | `saveState`/`restoreState`, состояние формы не теряется |

## Чего приложение НЕ делает

- не внедряет JavaScript и не меняет DOM/цены/ответы сервера;
- не перехватывает, не дублирует и не обходит платежи — всё платёжное взаимодействие идёт
  на официальных страницах сайта, ровно как в браузере;
- не запрашивает доступ к контактам, геолокации, камере, файлам;
- не собирает аналитику и не содержит сторонних SDK;
- `android:allowBackup="false"` — cookies и данные формы не попадают в облачный бэкап.

## Сборка

Готового APK в архиве нет: он собирается из исходников одним из двух способов ниже.

### Вариант 1 — без Android Studio (GitHub Actions, ~3 минуты)

APK соберётся в облаке, на компьютере ничего ставить не нужно.

1. Создать на github.com пустой репозиторий (можно приватный).
2. Загрузить туда **содержимое** папки `scbarena-parking-android`
   (кнопка «uploading an existing file» → перетащить папки `app`, `gradle`, `.github`
   и файлы `*.gradle.kts`, `gradle.properties`, `README.md`; папка `.github` должна
   попасть в корень репозитория).
3. Открыть вкладку **Actions** → workflow **Build APK** → **Run workflow**
   (он также запустится сам после первого коммита).
4. Через 2–4 минуты в разделе **Artifacts** появится `arena-parking-apk.zip` → внутри
   `app-debug.apk`. Скачать, распаковать, установить на телефон.

В облаке используется JDK 17 + Gradle 8.9, поэтому отсутствующий `gradle-wrapper.jar`
не мешает: сборка идёт командой `gradle assembleDebug`.

### Вариант 2 — Android Studio

Требуется Android Studio (Koala / Ladybug / Meerkat или новее), JDK 17 — он идёт в комплекте.

1. **File → Open** → выбрать папку `scbarena-parking-android`.
2. Дождаться Gradle Sync. Studio сама скачает Gradle 8.9 по `gradle/wrapper/gradle-wrapper.properties`.
   Если появится сообщение про отсутствующий `gradle-wrapper.jar` — нажать в нём **«Fix»/«OK»**,
   либо выполнить в терминале проекта один раз: `gradle wrapper --gradle-version 8.9`
   (нужен локально установленный Gradle), после чего Sync пройдёт.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Или из терминала (когда wrapper на месте):

```bash
./gradlew assembleDebug        # отладочный APK
./gradlew assembleRelease      # release APK, подписан отладочным ключом
```

Release-сборка намеренно подписана debug-ключом (`signingConfig = signingConfigs.getByName("debug")`) —
это личная сборка «для себя», ставится на телефон сразу. Для публикации в магазине
нужно заменить это на собственный keystore.

## Установка на телефон

1. Перекинуть APK на устройство (кабель, Telegram «Избранное», Google Drive).
2. Открыть файл, разрешить установку из неизвестных источников для файлового менеджера.
3. Android 14+ предупредит про приложение не из Play Маркета — это ожидаемо.

## Настройки под себя

- **Адрес** — `START_URL` в `app/src/main/java/ru/scbarena/parking/MainActivity.kt`.
- **Цвета иконки и интерфейса** — `app/src/main/res/values/colors.xml`
  (`brand`, `ic_launcher_background`).
- **Название** — `app_name` в `app/src/main/res/values/strings.xml`.
- **Список «внешних» доменов** — `EXTERNAL_HOSTS` в `MainActivity.kt`.
- **Полный immersive-режим** (скрыть статус-бар и панель навигации) — добавьте в `onCreate`:

```kotlin
WindowCompat.setDecorFitsSystemWindows(window, false)
WindowInsetsControllerCompat(window, binding.root).hide(WindowInsetsCompat.Type.systemBars())
```

Учтите: в immersive-режиме клавиатура может перекрывать поля формы, поэтому по умолчанию
режим выключен — статус-бар оставлен, а панель браузера отсутствует.

## Проверено / не проверено

Проверено: адрес `https://scbarena-nn.ru/parking/` открывается и отдаёт страницу
«ОПЛАТА ПАРКОВКИ» (выбор мероприятия, форма бронирования); все XML-ресурсы и ссылки между
ними согласованы; идентификаторы в коде совпадают с layout.

**Не проверено:** сборка APK и запуск на устройстве — в среде, где готовился проект, нет
JDK/Gradle и доступа к репозиториям зависимостей (нет даже `java`), поэтому dex-компиляция
и подпись APK там невозможны. Готового `.apk` в архиве нет намеренно: вместо «битого»
файла — воспроизводимая сборка (GitHub Actions или Android Studio). Первый запуск сборки
покажет, если что-то требует правки — пришлите лог, поправлю.

## Дисклеймер

Неофициальный клиент для личного использования. Не связан со стадионом, ФК «Торпедо»
или ООО «Совкомбанк Арена». Все данные, оплата и условия — на стороне официального сайта;
приложение лишь отображает его страницу.
